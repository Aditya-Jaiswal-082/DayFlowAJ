# Screenshots

The main README expects these four files:

| File | What to capture |
| --- | --- |
| `today.png` | The Today tab with a few tasks — at least one checked, one high priority with a reminder bell |
| `analysis.png` | The Analysis tab with a week of data so the charts aren't empty |
| `reminders.png` | The Reminders tab with something upcoming and something already fired |
| `expenses.png` | The Expenses tab with budgets set, including one overspent, and the split editor open |
| `split.png` | The Split tab with two or three people, one owing you and one settled |

Tips:

- Around **1200 × 800** looks right on GitHub without being huge.
- Take one set in light mode and, if you want, a dark-mode pair as `today-dark.png` etc.
- Hide anything personal — the notes and expense descriptions are the usual culprits.
- Add data first: an empty app makes for unconvincing screenshots.

Delete this file once the images are in.
